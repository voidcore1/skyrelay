# M1 clean profile, 2026-11-23

Metric: **bridge decode → consumer** (see the [README](README.md)). It excludes
the vehicle and link side. Target: overall p99 ≤ 100 ms. Result: pass.

## Setup

- Scenario: `bench/scenarios/m1-clean.env`: four PX4 SIH vehicles, no link
  impairment, bridge and probe on one host over loopback DDS.
- Pose published at a nominal 20 Hz per vehicle; 60 s recorded.
- Host: Intel Core i9-13900H, 20 logical cores, 15.3 GiB RAM, Linux 7.0.0-43-generic.
- Docker 29.1.3, PX4 v1.17.0 (SIH), Cyclone DDS 11.1.0, cyclonedds-cxx 11.1.0.
- SkyRelay commit 9276e73 plus the uncommitted benchmark tooling in this change.
  The preview build is the `dev` preset.

Gate: PASS: overall p99 0.212 ms is within 100 ms

Each vehicle delivered about 19.4 samples/s over the 60 s, a little under the
nominal 20 Hz. There were no seq gaps: no sample the bridge published was missed
by the probe. This is one 60 s run on one machine with nothing else loaded; it
shows the order of magnitude, not a distribution across runs.
